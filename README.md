#  AI Resume Screening & Job Matching System

##  Overview
This project is an end-to-end NLP-based system that matches resumes with job descriptions using BERT embeddings and cosine similarity.

It allows automated ranking of candidates based on relevance to job roles.

---

## 🧠 Features
- Resume text preprocessing
- BERT embeddings using PyTorch
- Cosine similarity matching
- PostgreSQL database storage
- FastAPI backend for real-time inference
- Top-N candidate ranking
